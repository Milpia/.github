# Milpia · .github

**Lo que todos los repositorios de Milpia comparten: la portada de la organización, la guía de estilo y las plantillas.**

## ✨ En 30 segundos

- **Qué es:** el repositorio especial de la organización. GitHub muestra
  `profile/README.md` en [github.com/Milpia](https://github.com/Milpia) y usa
  `.github/` como plantilla por defecto en todos los repos que no tengan la suya.
- **Para qué:** que cada proyecto se documente igual y que pasar de uno a otro
  se sienta familiar.
- **Es público:** aquí no va nada interno (ni hosts, ni IPs, ni clientes).

## 🧭 Empieza aquí

| Si vas a… | Usa |
|---|---|
| **escribir o rehacer un README** | [`plantillas/README.md`](plantillas/README.md) |
| **crear la puerta de entrada de `docs/`** | [`plantillas/docs-README.md`](plantillas/docs-README.md) |
| **escribir una receta o cualquier documento** | [`guia/estilo.md`](guia/estilo.md) |
| **abrir un PR** | La plantilla de PR se aplica sola en todos los repos ([`.github/pull_request_template.md`](.github/pull_request_template.md)) |

## 🤝 Contribuir

Los cambios entran por PR, como en cualquier repo de Milpia. Si cambias la
guía, revisa que las plantillas sigan de acuerdo con ella.
